# Phase 1 — OpenUSD and Omniverse

**Time:** 1–2 weeks

## Why this phase exists

Isaac Sim stages are OpenUSD stages. If you cannot inspect a prim, a payload, or a physics API, you cannot debug robots.

## Official path

- https://www.nvidia.com/en-us/learn/learning-path/openusd/
- https://docs.nvidia.com/learn-openusd/latest/index.html
- https://docs.nvidia.com/learning/physical-ai/physical-ai-agent-bootcamp/latest/index.html
- https://developer.nvidia.com/omniverse
- https://huggingface.co/datasets/nvidia/PhysicalAI-SimReady-Warehouse-01

## Practice

- Create a stage, add prims, set transforms
- Reference vs payload vs inherit
- Open a SimReady warehouse asset and find mass / collider metadata
- Agent Bootcamp: render a USD scene; build a gravity-enabled physics scene

## Done when

You can open a USD file, find the robot root, and explain how materials, collision, and articulation data are attached.
