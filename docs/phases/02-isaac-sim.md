# Phase 2 — Isaac Sim

**Time:** 2–3 weeks

## Official path

- https://docs.nvidia.com/learning/physical-ai/getting-started-with-isaac-sim/latest
- https://docs.isaacsim.omniverse.nvidia.com/latest/index.html
- https://developer.nvidia.com/isaac/sim
- https://github.com/isaac-sim/IsaacSim

## Project ladder

1. UI fluency: stage tree, viewport, Play, physics inspector
2. Assemble a simple wheeled body (official assemble-a-robot tutorial)
3. Import URDF / MJCF and fix joint drives
4. Sensors: RGB, depth, 2D lidar, IMU
5. Replicator synthetic data + domain randomization
6. ROS 2 bridge and a SIL drive-around

## Done when

You have a recorded clip of your imported robot moving under physics, plus one synthetic dataset folder you generated yourself.
