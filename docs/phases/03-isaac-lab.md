# Phase 3 — Isaac Lab

**Time:** 2–4 weeks

## Official path

- https://isaac-sim.github.io/IsaacLab
- https://github.com/isaac-sim/IsaacLab
- https://developer.nvidia.com/isaac/lab

Match Isaac Lab version to Isaac Sim version before you debug anything else.

## Learn

- Manager-based vs direct task APIs
- Vectorized environments on GPU
- PPO and imitation learning entry points
- Domain randomization and curriculum
- Isaac Lab-Arena style evaluation
- Export to ONNX / LEAPP for later ROS deploy

## Project ladder

1. Run a stock cartpole / locomotion script
2. Change reward or observation and retrain
3. Reach or lift on the Phase 2 robot
4. Save checkpoints and an eval video

## Done when

You can point to a checkpoint, a training curve, and a video of the policy in sim.
