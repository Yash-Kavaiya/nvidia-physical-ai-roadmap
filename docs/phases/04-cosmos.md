## Model cheat sheet

| Family | Job |
| --- | --- |
| Predict | Generate future world video from text / image / video |
| Transfer | Restyle or augment with spatial controls (depth, seg, lidar, HD map) |
| Reason | Physical VLM — what happened, what should happen next |
| Cosmos 3 | Unified omnimodel; Nano / Super / Edge sizes |
| Curator | Filter, annotate, deduplicate sensor video |
